## 6. LINE/Telegram notifier 接線規格（告警段的核心，最易踩坑）

> AOV 有現成 `notifier/` package，**不要自己寫 HTTP**。但它是 **async**，是最大整合坑。

### 6a. 可用的 notifier（證據）
| 管道 | 檔案 | class（行號） | 方法 |
|---|---|---|---|
| LINE（推薦，依賴最小用 httpx） | `notifier/line_bot.py` | `LineBotNotifier`（:19） | `async def send_daily_report(self, daily_summary: dict) -> bool`（:33-93） |
| Telegram（備選，多吃 python-telegram-bot 套件） | `notifier/telegram_bot.py` | `TelegramBotNotifier`（:20） | `async def send_daily_report(self, daily_summary: dict) -> bool`（:32-92） |

### 6b. 關鍵事實
- **token 來源**：兩者建構子預設從 `config.py` 讀（`line_bot.py:29` = `config.LINE_CHANNEL_ACCESS_TOKEN`；`config.py:37` = `os.getenv("LINE_CHANNEL_ACCESS_TOKEN","")`）。`config.py:11` 用 `load_dotenv` 從 repo 根 `.env` 載入。
- **graceful 內建**（重要，符合 Exit③）：token/user_id 未設時 `line_bot.py:43-47` 直接 log error + `return False`，**不發網路、不拋例外**。Telegram 同（`telegram_bot.py:42-46`）。→ health.py 無須自己判斷 token，notifier 自己會 graceful。
- **import 寫法**：`from notifier.line_bot import LineBotNotifier`（`notifier/__init__.py` 只有註解、不 re-export，**必須指到子模組**）。需以 **repo root 為 sys.path 起點**執行（即 `py -m gov.health`，與 `py -m gov.assertions` 同條件）。**不可用相對 import**（`notifier` 是 top-level，非 gov 子模組）。
- **import side effect**：`from notifier... import` 會連帶 `import config` → 觸發 `config.py:11` load_dotenv + `config.py:135-139` mkdir（建 data/、logs/）。對 health.py 無害，但測試要知道（最好 chdir repo root）。
- **payload 形狀**：`send_daily_report` 吃 dict 且只認 `daily_summary["title"]` 與 `["report_url"]`（`line_bot.py:50-51`）。G2 告警**借用**此方法：傳 `{"title": "<smoke 失敗摘要>", "report_url": ""}`。

### 6c. async 邊界（最大坑）
health.py 主體應**保持同步**（與 `gov/assertions.py` 等一致），只在發告警那一步用 `asyncio.run(...)` 包 async 呼叫（範例 `push_now.py:48-49`）：
```python
import asyncio
from notifier.line_bot import LineBotNotifier

def notify_via_aov(title: str) -> bool:
    """skill smoke 失敗時發 LINE 告警；token 未設→notifier 自己回 False（graceful）。"""
    payload = {"title": f"🔴 [GOV 健檢] {title}", "report_url": ""}
    try:
        return asyncio.run(LineBotNotifier().send_daily_report(payload))
    except Exception:
        return False  # 告警失敗不可拖垮健檢主流程
```

### 6d. 真實呼叫範例（照抄用）
- `main.py:702-703`：`line_bot = LineBotNotifier(); line_ok = await line_bot.send_daily_report(daily_summary)`
- `push_now.py:48-49`：`asyncio.run(main())`（示範同步 entry 驅動 async）
- 推薦：比照 `main.py:702-711` **LINE + Telegram 並排都發**（任一掛了還有另一個），但 G2 先接 LINE 即達標。

## 8. 測試計畫（`tests/test_health.py`，先寫再實作）

### 8a. 測試慣例（證據：test_assertions.py）
- 檔頭固定式（:1-10）：`from __future__ import annotations` → `import sys` + `from pathlib import Path` → `PROJECT_ROOT = Path(__file__).resolve().parent.parent` → `sys.path.insert(0, str(PROJECT_ROOT))` → 才 `from gov.health import ...`。
- `tmp_path` 造隔離 repo（:37-50），**所有 `write_text` 帶 `encoding="utf-8"`**（Windows cp950 陷阱）。
- 斷言 dict 欄位 + 中文契約訊息。

### 8b. 要測什麼
1. **graceful 不發**：token 未設時 `notify_via_aov` 回 False、不拋例外、不真發。
2. **smoke pass/fail 判定**：通過的 skill 計 pass、壞的進 failed。
3. **純 prompt skill skip**：無 test_skill.py 的 skill 不算 fail（防 instagram skill 永遠紅）。
4. **隔離 repo 不 crash**：乾淨 tmp_path 跑不炸。
5. **CLI exit code**：`main()` 回 0/1。

### 8c. mock 策略（避免測試真的發送，證據：子代理4）
- **最可靠**：`monkeypatch.setattr("gov.health.LineBotNotifier", FakeNotifier)`（patch 使用點），`FakeNotifier.send_daily_report` 設 `async def ... return True`。可斷言「smoke 失敗時有呼叫到告警」。
- **次選**：`monkeypatch.setattr("config.LINE_CHANNEL_ACCESS_TOKEN", "")`（runtime 動態讀取，會生效）。**不要用 `setenv`**——`config.py:37` 在 import 時就固化 os.getenv，setenv 後不生效。

### 8d. 骨架（佔位 API 名，回填後對齊）
```python
from __future__ import annotations
import sys
from pathlib import Path
PROJECT_ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(PROJECT_ROOT))
from gov.health import check_skill, run, notify_via_aov

def test_notify_graceful_when_no_token(monkeypatch):
    monkeypatch.setattr("config.LINE_CHANNEL_ACCESS_TOKEN", "")
    monkeypatch.setattr("config.LINE_USER_ID", "")
    assert notify_via_aov("test alert") is False  # graceful，不拋例外

def test_skill_without_test_is_skipped_not_failed(tmp_path: Path):
    d = tmp_path / ".agent" / "skills" / "promptonly"
    d.mkdir(parents=True)
    (d / "SKILL.md").write_text("x", encoding="utf-8")
    rep = check_skill(d, tmp_path)
    assert rep["ok"] is True  # 無 test → skip 非 fail

def test_run_clean_on_empty_repo(tmp_path: Path):
    (tmp_path / ".agent" / "skills").mkdir(parents=True)
    rep = run(notify=False)  # 注意：run 用 find_repo_root，測試可能要傳 root 參數，回填時對齊
    assert isinstance(rep.get("failed"), list)
```

## 12. 待主公/執行者拍板的點（誠實標註不確定）

1. **告警借用 `send_daily_report` 是權宜**：該方法綁「每日報告」語意（只認 title/report_url）。乾淨做法是在 `notifier/` 加一個通用 `send_text(msg)`，但那會**改 notifier、擴大 scope**。建議 G2 先借用（最小改動），未來另議是否加通用方法。
2. **LINE only 還是 LINE+Telegram 都接**：本冊推薦先接 LINE 達標；要不要比照 main.py 兩個都發，執行時定。
3. **run() 是否加 `root` 參數**：源 `run()` 內部呼叫 `find_repo_root()`，測試難隔離。建議加 `root: Path | None = None` 參數（預設 find_repo_root），方便 tmp_path 測試——回填時對齊測試骨架。
