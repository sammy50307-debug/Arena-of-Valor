## 附錄：PoC 正規化邏輯草案（已驗證，完整原型見 scratch/poc_normalize_proto.py）

5 類格式 → ISO `YYYY-MM-DD HH:MM:SS`（now = 爬取當下）：

1. **ISO 完整** `YYYY-MM-DD [HH:MM[:SS]]`（舊文，如 `2025-12-26`）→ 直接重格式化
2. **N 小時/分鐘/天前**（如 `10 小時前`）→ `now - timedelta(...)`
3. **昨天 HH:MM** → `(now - 1天).replace(時分)`
4. **前天 HH:MM** → `(now - 2天).replace(時分)`
5. **MM-DD HH:MM**（無年份，最大宗，如 `04-27 17:58`）→ 補 now.year；若補後 > now+1天 則回退去年（跨年保護）

失敗（皆不匹配）→ 回傳 None，呼叫端 `or published` 保留原值（D3 回退）。

**PoC 鐵證**：涵蓋性 37/37（真實去重全集 100%）；生效性 `2 小時前` 0.300→0.972、`10 小時前` 0.300→0.861、`昨天 22:39` 0.300→0.662；跨年 `12-26 10:00` 在 2026-06-02 → `2025-12-26`。
