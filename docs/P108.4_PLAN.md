## 1. 目標 (Objective) ─ 必填

讓非巴哈無日期文（Tavily/DDG 搜尋結果，timestamp 為「時間未知」/空/無法解析）能進「最新動態」候選池，picker 對其給差異化 decay（**芽芽相關 0.6 / 芽芽無關 0.3**），使芽芽相關多平台文被看到、又不讓網頁雜訊壓過巴哈真實新文。**不造假 fallback 日期**——無日期就誠實維持「時間未知」顯示。並加**時間欄位端到端契約測試**作為防復發 guard，一次守住 P108.3（巴哈 ISO）/P108.3.1（重建層）/P108.4（無日期）三修。

## 2. 觸發背景 (Why Now) ─ 必填

R-032：非巴哈平台 published_date 100% 空值，被 generator `_has_known_post_date` gate 擋出最新動態池 → 池子幾乎只有巴哈文。飛輪分析（第二次追問「更好做法」）揭露 P108.3/3.1/4 是同一條「時間流到 picker」鏈上的三個洞；採穩修（E′ + 契約 guard）解痛點 + 防整類復發，不造假日期（更誠實、更 surgical）、不重構（反膨脹停損）。decay 策略（芽芽 0.6/無關 0.3）由阿喜定。
