## 什麼做對了

### 核心設計：四層縱深防禦

```
Layer 1  UserPromptSubmit hook   — 每 prompt 觸發，注入鐵律提醒
Layer 2  MEMORY.md 鐵律區塊      — 新視窗載入時讀到
Layer 3  CLAUDE.md 禁令           — 專案層級持久規則
Layer 4  TASK_HISTORY.md 警語    — 檔案層級最後防線
```

**設計思路**：單一防線容易被遺忘或繞過；四層縱深確保即使某一層失效，其他層仍有效。

### 量化成果（實測）

| 指標 | 結果 |
|---|---|
| TASK_HISTORY 全讀節省 | **96.8%** token（預測 92-96%） |
| 新增元件數 | 13 元件（hook scripts + md files + tests） |
| 單元測試覆蓋 | 4 個 hook 測試腳本 |

### 可複用的設計模式

1. **縱深防禦**：重要規則不只寫一個地方，至少三層重複
2. **機械化觸發**：不依賴「主公記得」，用 hook 自動注入
3. **鐵律二次確認**：高風險動作（全讀 135K tokens）需「這次」+「全讀」雙詞觸發，防誤觸
